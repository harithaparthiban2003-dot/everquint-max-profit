# EverQuint Max Profit Problem

## 1. Problem Overview

The objective of this problem is to calculate the maximum
earnings possible by constructing Theatres, Pubs, and
Commercial Parks within a given time period.

Only one property can be constructed at a time.
Once construction is completed, the property starts
generating earnings for the remaining time.

## 2. Property Details

| Property | Construction Time | Earnings per Time Unit |
|----------|------------------:|-----------------------:|
| Theatre (T) | 5 | $1,500 |
| Pub (P) | 4 | $1,000 |
| Commercial Park (C) | 10 | $2,000 |

## 3. Objective

Find the combination and construction sequence that
produces the maximum total earnings for the given
available time.

## 4. Technologies Used

- Python 3
- Recursion
- Functions
- Sets and tuples

## 5. Approach

1. Accept the available time as input.
2. Explore possible property construction sequences.
3. Calculate the earnings generated by each property.
4. Compare the total earnings of different sequences.
5. Track the maximum earnings and corresponding
   property combinations.
6. Display the maximum earnings and the solutions.

## 6. How to Run

### Requirements
Python 3 must be installed.

### Steps

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

   python max_profit.py

4. Enter the available time when prompted.
5. View the maximum earnings and property combinations.
